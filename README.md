Weapon sources

The sources field indicates how a weapon can be obtained in game.
Possible values are:

* wish → obtained via gacha banners

* event → limited-time event reward

* forge → craftable at the blacksmith

* boutique → purchasable from NPC shops

* battle_pass → battle pass reward

* fishing_inazuma → obtained via Inazuma fishing system

* story_quest → obtained during a story quest

* narzissenkreuz_quest → obtained during the Narzissenkreuz questline

* ar10 → obtained when reaching Adventure Rank 10
