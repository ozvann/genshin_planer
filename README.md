# genshin_planer
C'est un projet demandé par une de mes connaissances


Weapon sources

La catégorie des sources indique comment une arme peut être obtenue dans le jeu.
Les valeurs possibles sont :

* wish → obtenue via le système de gacha

* event → ce sont les récompenses durant les événements à temps limité

* forge → peut être créée chez le forgeron (il faut aussi acheter les plans pour les créer)

* boutique → achetable dans la boutique du jeu pour les 4 ★, pour les ★ inférieur à 4 ce sont des marchands dans le monde qui en vendent

* battle_pass → récompense du battle pass

* fishing_inazuma → obtenue via le système de pêche d'Inazuma

* fishing_sumeru → obtenue via le système de pêche de sumeru

* fishing_fontaine → obtenue via le système de pêche de fontaine

* story_quest → obtenue via une quête d’histoire

* narzissenkreuz_quest → obtenue durant la suite de quête de Narzissenkreuz

* ar10 → obtenue quand on arrive au niveau d'Aventurier 10


Weapon main_stat


Toutes les armes possèdent une statistique obligatoire (attaque flat), elle est différente pour chaque arme. Le champ main_stat représente uniquement la statistique secondaire de l’arme.

* phys_dmg → augmente les dégâts physiques infligés (en %)

* atk → augmentation de l'attaque du personnage (en %)

* hp → augmentation des points de vie du personnage (en %)

* def → augmentation de la défense du personnage (en %)

* er → augmentation de la recharge d'énergie du personnage (en %)

* em → augmentation de la maîtrise élémentaire du personnage

* crit_rate → augmentation du taux critique du personnage (en %)

* crit_dmg → augmentation des dégâts critiques du personnage (en %)

* none → aucune amélioration de statistique du personnage (généralement vide sur les détails de l’arme)


Character affiliation

La catégorie affiliation indique l'affiliation du personnage:

* nation (mondstadt, liyue, inazuma, sumeru, fontaine, natlan, nod_krai, snezhnaya)

* origine spéciale (otherworld, cosmic_calamity, paradisia_millistral)

* collaboration (colab)

element

* Les éléments listés représentent les éléments accessibles au personnage, mais pas nécessairement simultanément.

* La catégorie element représente les éléments accessibles, ceux marqués avec plusieurs éléments sont capables de permuter d'élément via les statues des Sept.
